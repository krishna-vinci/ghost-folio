# Changelog

## 1.0.0 — 2026-10-20

- Landing page with hero, featured and pinned posts, selected projects, latest video, latest writing and a newsletter sign-up.
- Projects collection with status and stack chips, a client-side stack filter and a project case-study template.

- Subtle motion that respects `prefers-reduced-motion`; all content is readable without JavaScript.
- Theme settings for homepage sections, post metadata and related articles.
